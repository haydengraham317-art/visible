## Standing contact block

Goes under every post, exactly as written:

```
📞 (902) 221-4582
📧 doucetlandscaping@gmail.com
🌐 doucetlandscaping.ca
```

Neither Instagram nor TikTok makes a URL in a caption clickable — it's display
text only. So it also needs to be set up where people can actually tap it:

- **Instagram** — `doucetlandscaping.ca` in the bio link, and turn on the
  business "Call" and "Email" action buttons so the phone number is one tap.
- **TikTok** — website field in the bio (needs a Business account), phone in the
  bio text.

One flag: a plain email address in a public caption gets scraped by spam bots,
and that Gmail will start collecting junk. His call — but the IG Email button
does the same job without exposing the address to crawlers.

## Which video goes where

| Platform | File | Why |
|---|---|---|
| TikTok | `doucet-short-cut-vertical.mp4` (0:16) | Short-form wins; 16s holds retention |
| Instagram Reels | `doucet-short-cut-vertical.mp4` (0:16) | Same cut, same reason |
| IG feed / carousel | `doucet-full-tour-square.mp4` (0:40) | Square reads better in-grid |
| Follow-up post | `doucet-full-tour-vertical.mp4` (0:40) | Full tour, 2–3 days later |

**Don't cross-post the TikTok export to Instagram.** A TikTok-watermarked file
gets suppressed in the Reels algorithm. Export clean from CapCut once, then
upload that same file separately to each platform.

Hashtags: Instagram is fine with 10–12, in the caption or the first comment.
TikTok, keep it to 3–5 — more than that dilutes the topic signal.

Location tags assume this job was in the HRM. Swap the geo hashtags if it
wasn't.
